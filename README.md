# Fouzan Dev Portfolio

A modern and responsive portfolio website built using **HTML**, **Tailwind CSS v4**, and **JavaScript**.

This portfolio showcases my skills, projects, education, internship experience, and contact information in a clean and interactive user interface.

## Features

* Responsive Design
* Modern UI/UX
* Animated Hero Section
* Interactive Navigation Menu
* Skills Showcase
* Education Timeline
* Project Gallery
* Contact Section
* Resume Download
* Social Media Links
* Tailwind CSS v4 Theme System

## Technologies Used

* HTML5
* Tailwind CSS v4
* JavaScript
* Vite

## Sections

* Home
* About
* Skills
* Education
* Experience
* Projects
* Contact

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/fouzan-dev-portfolio.git
```

Navigate to the project directory:

```bash
cd fouzan-dev-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
